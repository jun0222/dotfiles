# /editclaudecommand — 既存の Claude コマンドを編集する

`.claude/commands/` にある既存のコマンド定義ファイルを対話的に修正する。

## 使い方

```
/editclaudecommand [コマンド名] [変更内容の説明]
```

| 引数 | 説明 |
|---|---|
| `[コマンド名]` | 編集するコマンド名（省略時は一覧から選ぶ） |
| `[変更内容の説明]` | 何を変えたいか（省略時は内容を見てから聞く） |

## 処理内容

### 1. 引数をパース

- 第1引数 → コマンド名
- 残り → 変更内容の説明（任意）

### 2. コマンドを特定する

#### コマンド名が指定された場合

`.claude/commands/<コマンド名>.md` が存在するか確認する。
存在しない場合:
```
"<コマンド名>.md" が見つかりません。
利用可能なコマンド: addclaudecommand, addsh, log, marp, todo, ...
```
と出力して終了。

#### コマンド名が省略された場合

`.claude/commands/` 内の `.md` ファイルを列挙してユーザーに選ばせる:

```
編集するコマンドを選んでください:
  1. addclaudecommand
  2. addsh
  3. log
  4. marp
  5. todo
  ...

番号または名前を入力:
```

### 3. 既存ファイルを Read して現在の内容を表示する

```
📄 <コマンド名>.md の現在の内容:
──────────────────────────────────────
<ファイルの内容>
──────────────────────────────────────
```

### 4. 変更内容をヒアリングする

#### 変更内容の説明が引数で渡された場合

そのまま次のステップへ。

#### 変更内容の説明がない場合

```
何を変更しますか？（例: 「デフォルトの出力先を変えたい」「--dry-run オプションを追加したい」）
```

とユーザーに聞く。ユーザーの回答が曖昧な場合はさらに深堀りする。

### 5. 変更案を生成してプレビューを表示する

変更の内容・規模に応じて:

- **部分修正**（特定の行・セクション変更）→ diff 形式で変更箇所だけ表示
- **大幅な変更**（構成を変える・セクション追加など）→ ファイル全体をプレビュー

```
以下の変更を行います:

--- 変更前
+++ 変更後
@@ ... @@
 （diff）

適用しますか？ [y/N/さらに修正]
```

- `y` → Write して完了
- `N` → 中断
- `さらに修正` → ステップ 4 に戻る

### 6. ファイルを Write する

変更後の内容でファイルを上書き保存する。

### 7. 完了メッセージを出力する

```
✓ .claude/commands/<コマンド名>.md を更新しました
```

最後に `open .claude/commands/<コマンド名>.md` を実行してエディタで開く。

## ルール

- ユーザーが確認した内容だけを書き込む（勝手に追加・削除しない）
- コマンドの意図・目的が変わる大きな変更は、変更前に必ず確認する
- 変更が不要と判断した場合は「変更箇所がありません」と伝えて終了する

## 実行例

```
/editclaudecommand addsh
/editclaudecommand todo --fileのデフォルトパスを~/Desktop/todo.mdからカレントディレクトリのTODO.mdに変えたい
/editclaudecommand log --error以外にも--warnフラグを追加したい
/editclaudecommand marp スライド数のデフォルトを8から5に変えて
```
