# /addsh — zshrc / bashrc にエイリアス・関数を追加する

このリポジトリの `.zshrc` または `.bashrc` に新しいエイリアスや関数を追記する。

## 使い方

```
/addsh <名前> <コマンド> [--zsh|--bash] [--section <セクション名>] [--function]
```

| 引数 | 説明 | デフォルト |
|---|---|---|
| `<名前>` | エイリアス/関数名（必須） | — |
| `<コマンド>` | 実行するコマンド文字列（必須） | — |
| `--zsh` / `--bash` | 対象ファイル | `--zsh` |
| `--section <name>` | 挿入するセクション名（部分一致） | 自動推定 |
| `--function` | 関数テンプレートとして追加 | エイリアスとして追加 |

## 対象ファイル

- `--zsh` → `<repoルート>/.zshrc`
- `--bash` → `<repoルート>/.bashrc`

## 処理内容

### 1. 引数をパース

- `<名前>` と `<コマンド>` が未指定の場合は使い方を表示して終了
- `--zsh` / `--bash` フラグを検出（未指定は `--zsh`）
- `--section` の値を取得（未指定は後述の自動推定）
- `--function` フラグを検出

### 2. 対象ファイルを Read する

`<repoルート>/.zshrc` または `<repoルート>/.bashrc` を Read する。

### 3. 挿入コードを生成する

#### `--zsh`（`.zshrc`）の場合

**エイリアス（デフォルト）:**
```zsh
ae <名前> "<コマンド>"
```

**関数（`--function`）:**
```zsh
<名前>(){
    _fd $0
    <コマンドを1行目として挿入>
}
```

#### `--bash`（`.bashrc`）の場合

**エイリアス（デフォルト）:**
```bash
alias <名前>='<コマンド>'
```

**関数（`--function`）:**
```bash
<名前>() {
    <コマンドを1行目として挿入>
}
```

### 4. 挿入位置を決定する

#### セクション検索（`--section` 指定時 or 自動推定時）

**.zshrc** のセクション区切り形式:
```
# ---------------------------------------------------------------------
# <セクション名>
# ---------------------------------------------------------------------
```

**.bashrc** のセクション区切り形式:
```
# ====================
# <セクション名>
# ====================
```

**自動推定ロジック（`--section` 未指定時）:**

コマンド内容から下記のキーワードでセクションを推定する:

| コマンドに含まれる語 | 推定セクション（.zshrc） | 推定セクション（.bashrc） |
|---|---|---|
| `git`, `gph`, `gb` 等 | `Git（エイリアス）` | `alias 設定` |
| `docker`, `dx` 等 | `Docker` | `alias 設定` |
| `npm`, `node` 等 | `ビルド` | `alias 設定` |
| `cd`, `desktop` 等 | `ナビゲーション` | `alias 設定` |
| それ以外 | `ファイル操作 / ユーティリティ` | `alias 設定` |

対象セクションの**末尾の空行の直前**に挿入する。セクションが見つからない場合はファイル末尾に追記する。

### 5. ファイルを Write する

挿入後の内容でファイルを上書き保存する。

### 6. 完了メッセージを出力する

```
✓ .zshrc に追加しました
  セクション : <セクション名>
  追加内容   : ae <名前> "<コマンド>"

反映するには: source ~/.zshrc
```

## ルール

- 既存の行は**絶対に削除・変更しない**
- 同名のエイリアス/関数がすでに存在する場合は警告して中断する（上書きしない）
- `--function` で追加した関数は最低限のテンプレートのみ挿入する（ロジックはユーザーが編集）
- コマンド文字列にダブルクォートが含まれる場合は適切にエスケープする

## 実行例

```
/addsh gst "git status"
/addsh gst "git status" --zsh --section Git
/addsh cdwork "cd ~/Desktop/work" --zsh --section ナビゲーション
/addsh tfp "terraform plan" --bash
/addsh myserver "cd ~/srv && python3 -m http.server 8080" --zsh --section ユーティリティ
/addsh cleanup "git branch | grep -v main | xargs git branch -d" --zsh --section Git
/addsh sqlinit "docker exec db mysql -u root -p" --zsh --section Docker
/addsh mygrep "grep -rn --include='*.ts'" --zsh --function
```
